# DataForge.Web 最小可用（2026-03-22）

## 范围

用户选定：Web 先跑现有源，多源 NuGet（MySQL/Excel/Http）后补。

## 交付

- `tools/DataForge.Web`：静态页 `wwwroot/index.html` + `POST /api/jobs/run`
- 引用 Jobs 核心与 Sqlite / PostgreSql / SqlServer / Parquet / DuckDB 适配包
- `JobWebRunner.RunYamlAsync` 解析多 job YAML，失败即停
- 测试 `DataForge.Web.Tests`：csv→json 写出 2 行；空 yaml 返回 400。2/2 通过

## 启动

```bash
dotnet run --project DataForge.Core/tools/DataForge.Web
```
