# 最终目标梳理（对照阿里云 DTS + LocalDts）

## 结论

产品定位确认：**引擎底座（NuGet Jobs）+ 本机/在线控制台**。

- 学阿里云 DTS：任务生命周期、迁移/同步/订阅分层、对象选择与预检；**不**做云托管与完整 CDC。
- 学 LocalDts：本地插件式迁移、双 UI、连接探活/表结构/预览；**引擎以 DataForge.Jobs 为准**，不合并两套运行时。
- 下一跃迁：Web/CLI 控制台产品化（连接档案、对象浏览器、预检、进度），不是继续堆连接器。
