## Stage2 — Sqlite ↔ MySQL（YAML 手测）

环境：

```powershell
docker run -d --name dataforge-mysql `
  -e MYSQL_ROOT_PASSWORD=dataforge -e MYSQL_DATABASE=dataforge `
  -e MYSQL_USER=dataforge -e MYSQL_PASSWORD=dataforge `
  -p 3307:3306 mysql:8.0 --default-authentication-plugin=mysql_native_password
```

- 连接串：`Server=127.0.0.1;Port=3307;Database=dataforge;User ID=dataforge;Password=dataforge;AllowPublicKeyRetrieval=True;SslMode=None`
- CLI：`dotnet tools/DataForge.Sync/bin/Release/net8.0/DataForge.Sync.dll`
- 辅助脚本（未入库）：`DataForge.Core/artifacts/stage2-mysql-accept.ps1`

流程与结果：

1. SQLite 源表 `orders` 3 行（含 1 行 `Amount<=0`）
2. `dataforge preflight … --schema`（sqlite→mysql）→ errors=0
3. `dataforge run` → `Reconciled: read=3 skipped=0 filtered=1 rejected=0 written=2 difference=0`
4. MySQL 校验：`COUNT=2, SUM(Amount)=30`
5. `dataforge preflight … --schema`（mysql→sqlite）→ errors=0
6. `dataforge run` → written=2，对账 difference=0
7. SQLite 回写校验：`OrderId=2 → Bob=20.0`
8. 清理临时 MySQL 表

结论：**STAGE2 MYSQL ACCEPTANCE OK**
