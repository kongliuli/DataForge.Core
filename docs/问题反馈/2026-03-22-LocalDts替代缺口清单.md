## 2026-10-18 本轮落地（预检 / 对账 / 分发）

### Oracle/Mongo：明确不覆盖（范围结论）

- 仓库内 `DataForge.Jobs.*` 适配器共 8 个：sqlite、postgresql、sqlserver、mysql、excel、http、parquet、duckdb；**没有 Oracle / MongoDB 适配器包**，也没有可用于验收的实库。
- 因此本轮不做 Oracle/Mongo 移植，也不把它算作「隐性待补缺口」：需要时按 `IJobSource`/`IJobSink` 自行实现，注册方式与其余 8 个适配器一致（`AddDataForgeJobsXxx()`）。
- 若要真正覆盖，需同时提供：适配器包 + Catalog provider（探活/列表/结构/预览）+ 真实实例验收环境。

- 关系库水位已下推 `WHERE column > @watermark`（sqlite / postgresql / sqlserver / mysql）；文件源仍是客户端过滤
- 调度已进 NuGet：`JobScheduler` + 进程内 `JobScheduleService`；Web `/api/schedules` 支持注册、列出、立即运行、移除，同一作业串行执行。注册已通过 ScheduleFileStore 持久化，Web PersistentSchedules 启动时验证并恢复注册；Windows 服务安装和生命周期并发强化仍需验收。进程停止期间不执行任务，注册恢复不代表正在运行的迁移可断点恢复
- Web 运行可传 `variables`，页面用 `KEY=VALUE` 行替换 YAML 里的 `${KEY}`（水位列、状态路径、join 源一并替换）
