# LocalDts → DataForge 替代缺口清单

目标：Templates/Web/CLI 替代 LocalDts；NuGet（Jobs + 连接器）拥有全部迁移能力。

## 本轮已落地

1. 作业进度：`JobProgress` + `JobRunner`/`JobBatch` `IProgress`
2. YAML `execution`：并行度、失败是否停止、进度间隔、batchSize 写入 sink.options
3. Excel/Parquet Catalog（路径当 connection）

## 本轮增量水位

- YAML `watermark.column` + `watermark.statePath`（可选 `initial`）
- 只写出大于已存水位的行，成功后把见到的最大值写回状态文件
- 模板样例 `jobs/07-watermark.yaml`
- Web SSE 进度与 Http/DuckDB Catalog 已在 `fdc97e7`

## 待完成与验收边界（2026-10-18 复核）

不能把未核对的 LocalDts 能力直接视为非阻塞：当前目标是完整替代，以下项目完成或有明确范围结论前，不宣称最终验收通过。

| 工作包 | 验收条件 | 当前缺口 |
|---|---|---|
| 无代码配置与映射 | 从连接档案选择源/目标和列，配置转换，生成可执行 YAML | Web 主要仍为 YAML 输入；向导和映射编辑待补 |
| 预检与对账 | 执行前给出配置/连接/对象/类型报告；执行后行数对账并呈现坏行 | Catalog 原子查询已有；统一作业预检、对账闭环未完成 |
| 任务生命周期 | 保存、版本、重跑、停止和失败重试均有清晰状态 | 调度持久化已有；普通作业管理与批量调度仍需补齐 |
| 长任务可靠性 | 中断恢复不丢数据，重复写入策略明确；常驻宿主可部署 | 水位不是通用 checkpoint；需恢复、压力与关闭测试 |
| LocalDts 场景覆盖 | 逐项对照实际插件/转换器并提供替代场景证据 | Oracle/Mongo 等未覆盖，完整对照矩阵待建立 |
| 独立交付 | 在新目录仅安装 NuGet/模板即可跑通跨库迁移 | 打包可通过；脱离源码、实库与安装验收待完成 |

最近验证：Sync 45/45（排除 PostgreSqlLive）；解决方案 Release pack 退出码 0。该证据不代表全产品验收，仍有 CS8425、CS8620 和模板 NU5128 警告。

- 更多驱动按需移植（Oracle/Mongo 等）
- 关系库水位已下推 `WHERE column > @watermark`（sqlite / postgresql / sqlserver / mysql）；文件源仍是客户端过滤
- 调度已进 NuGet：`JobScheduler` + 进程内 `JobScheduleService`；Web `/api/schedules` 支持注册、列出、立即运行、移除，同一作业串行执行。注册已通过 ScheduleFileStore 持久化，Web PersistentSchedules 启动时验证并恢复注册；Windows 服务安装和生命周期并发强化仍需验收。进程停止期间不执行任务，注册恢复不代表正在运行的迁移可断点恢复
- Web 运行可传 `variables`，页面用 `KEY=VALUE` 行替换 YAML 里的 `${KEY}`（水位列、状态路径、join 源一并替换）
