# LocalDts → DataForge 替代缺口清单

目标：Templates/Web/CLI 替代 LocalDts；NuGet（Jobs + 连接器）拥有全部迁移能力。

## LocalDts 能力矩阵

| 能力 | LocalDts | DataForge 现状 | 优先级 |
|---|---|---|---|
| 连接探活 | DatabaseHelper.TestConnection | `JobCatalog.TestConnectionAsync` ✅ | — |
| 列库表 | GetTables | `JobCatalog.ListTablesAsync` ✅ | — |
| 表结构 | GetTableStructure | `JobCatalog.DescribeTableAsync` ✅ | — |
| 数据预览 | PreviewData | `JobCatalog.PreviewAsync` ✅ | — |
| 表是否存在 | TableExists | `JobCatalog.TableExistsAsync` ✅ | — |
| 作业执行 | MigrationEngine | JobRunner / Web / Sync CLI ✅ | — |
| 多源插件 | 30+ | Jobs.* 8 类 + Core 连接器 | P2 按需 |
| 转换器插件 | 多个 Transformer | YAML select/where/join | P1 增强 |
| WPF UI | 有 | 不做；Web+CLI 替代 | — |
| Blazor/Web | WebDts.Blazor | DataForge.Web（Catalog+连接档案+YAML） ✅ | P1 再美化 |
| 进度回调 | IProgress | 仅结果/历史 | P1 |
| 批处理/并行选项 | ExecutionOptions | 管道侧有，Jobs YAML 弱 | P1 |
| 模板开箱 | 无 | `dataforge-showcase` LocalDts 替代说明 ✅ | — |

## 本轮已落地

1. NuGet：`DataForge.Jobs.Catalog` + Sqlite/PostgreSql/SqlServer/MySql CatalogProvider
2. Web：`/api/catalog/*`、`/api/connections`、连接档案页
3. Templates README 升级为 LocalDts 替代脚手架说明
4. 测试：`JobCatalogTests`（Sqlite 探活/列表/结构/预览/存在性）

## 仍可增强（非阻塞验收）

- YAML 进度事件 / 并行度选项
- Excel/Http/Parquet 的 Catalog（文件类与关系库不同）
- Web UI 连接档案下拉绑定 `connectionId`
