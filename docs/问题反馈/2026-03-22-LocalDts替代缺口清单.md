# LocalDts → DataForge 替代缺口清单

目标：Templates/Web/CLI 替代 LocalDts；NuGet（Jobs + 连接器）拥有全部迁移能力。

## LocalDts 能力矩阵

| 能力 | LocalDts | DataForge 现状 | 优先级 |
|---|---|---|---|
| 连接探活 | DatabaseHelper.TestConnection | `JobCatalog.TestConnectionAsync` ✅ | — |
| 列库表 | GetTables | `JobCatalog.ListTablesAsync` ✅ | — |
| 表结构 | GetTableStructure | `JobCatalog.DescribeTableAsync` ✅ | — |
| 数据预览 | PreviewData | `JobCatalog.PreviewAsync` ✅ | — |
| 表是否存在 | TableExists | `JobCatalog.TableExistsAsync` ✅ | — |
| 作业执行 | MigrationEngine | JobRunner / JobBatch / Web / Sync CLI ✅ | — |
| 进度回调 | IProgress | `IProgress<JobProgress>` ✅ | — |
| 批处理/并行 | ExecutionOptions | YAML `execution.parallelism/stopOnError/progressEvery/batchSize` ✅ | — |
| 文件 Catalog | — | excel 工作表 + parquet 文件 ✅ | — |
| 多源插件 | 30+ | Jobs.* 8 类 + Core 连接器 | P2 按需 |
| 转换器插件 | 多个 Transformer | YAML select/where/join | P2 |
| WPF UI | 有 | 不做；Web+CLI 替代 | — |
| Blazor/Web | WebDts.Blazor | DataForge.Web（Catalog+连接档案+YAML） ✅ | P2 再美化 |
| 模板开箱 | 无 | `dataforge-showcase` LocalDts 替代说明 ✅ | — |

## 本轮已落地

1. 作业进度：`JobProgress` + `JobRunner`/`JobBatch` `IProgress`
2. YAML `execution`：并行度、失败是否停止、进度间隔、batchSize 写入 sink.options
3. Excel/Parquet Catalog（路径当 connection）

## 仍可增强（非阻塞验收）

- 更多驱动按需移植（Oracle/Mongo 等）
- Web UI 实时进度推送（当前是 API 回调，页面仍是结果历史）
- Http/DuckDB Catalog
