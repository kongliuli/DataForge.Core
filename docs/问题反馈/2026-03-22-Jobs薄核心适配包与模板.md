# Jobs 薄核心 + 适配包 + 展示模板（2026-03-22）

## 目标

把厚核心 `DataForge.Jobs` 拆成薄核心 + `DataForge.Jobs.*` 适配包，并加 `DataForge.Templates` 展示模板。

## 结果

- `DataForge.Jobs`：只内置 csv/json + `JobProviderRegistry`
- 适配包：Sqlite / PostgreSql / SqlServer / Parquet / DuckDB，各自 `AddDataForgeJobs*()`
- `DataForge.Sync`：薄 CLI，启动时注册全部适配包
- `DataForge.Templates`：`dotnet new dataforge-showcase`
  - `jobs/01-homo.yaml` 同构
  - `jobs/02-split-*.yaml` 单表拆多表（两个 job）
  - `jobs/03-merge.yaml` 异构列投影

## 验收

- `dotnet test`（排除依赖本机 PG 的 SqlitePostgreSql 过滤）：Core 164、Integration 11、Sync 13、SchemaInfer 1 通过
- Sync 测试用 `[ModuleInitializer]` 注册适配包，否则 parquet 会报未注册

## 说明

多表 JOIN 仍不是单条 YAML 能力；N→1 展示用「已投影的源表 + select 重命名」。
